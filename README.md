# 🏕️ Camp — Background Design Webpage

A simple camping-themed webpage created using HTML and CSS, featuring a scenic background image, centered text, and a transparent content overlay.

## ✨ Features

* Scenic background image using CSS
* Cover-sized background for the webpage
* Large, centered **Camp** heading
* Tagline: *“A camp trip to a peaceful place.”*
* Semi-transparent white content section
* White text for visual contrast

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
camp-trip-landing-page/
├── index.html
├── Camp.png
└── README.md
```

## 🎨 Design Highlights

The webpage uses a background image to establish a peaceful camping atmosphere. White text and a semi-transparent white overlay create a simple visual presentation while keeping the content prominent.

## 🚀 How to Run

1. Download or clone this repository.
2. Place `Camp.png` in the same folder as `index.html`.
3. Open `index.html` in your web browser.
